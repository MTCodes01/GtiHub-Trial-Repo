# Mentor Guide

Thank you for volunteering as a mentor for the Commit Overflow event! Your role is crucial in helping newcomers learn and contribute effectively.

## Responsibilities

1. **Triage Issues**: Help assign labels (`beginner`, `intermediate`, `bug`, etc.) to incoming issues.
2. **Assign Issues**: When a contributor asks to work on an issue, assign it to them. Ensure they don't have multiple open assignments to give others a chance.
3. **Provide Guidance**: Answer questions in issue threads and on PRs. Provide constructive, kind, and clear feedback.
4. **Code Review**: You are the first line of review for PRs. 

## The Review Process

When reviewing a PR:
- Check if it solves the linked issue.
- Verify the code quality and tests.
- Ensure the contributor followed the PR template.
- If changes are needed, explicitly Request Changes.
- If everything looks good, approve the PR and add the `ready-to-merge` label.

## Communication Guidelines

- Always be encouraging. Use phrases like "Great start!" or "Thanks for this contribution."
- Explain *why* a change is needed, rather than just dictating it.
- Point to documentation or resources when explaining complex concepts.
